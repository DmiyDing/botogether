怎么让 Claude Code 和 Codex 互相检查代码？

在 Botogether 里建一个群，放进一个用 Claude Code 的助手和一个用 Codex 的助手，绑定同一个项目目录，然后说清分工，比如「@开发 改代码，@检查 来验收」。在任务详情核对分工，再根据实际检查结果验收。

步骤

  1. 装好两个智能体

    电脑上已经装了 Claude Code 和 Codex，Botogether 会自动找到。在「设置 → 智能体」里，支持的系统也能一键安装。登录还是用你自己的账号。

  2. 建两个助手

    点 +，一个选 Claude Code，一个选 Codex。起个一看就懂的名字，比如「开发」和「检查」，各自选模型。

  3. 建群，绑一个目录

    再点 +，建一个群，选这两个助手，绑定它们要一起干活的项目目录。

  4. 说清谁做谁查

    用助手的真实名字：「@开发 修一下小屏手机上的结算页布局。@检查 在三种屏幕尺寸上验收。」

  5. 看结果

    在任务详情核对分工和文件证据。如果还需要检查或修改，就用实际名称 @ 相应助手。

要注意

  • 谁做谁查都可以换。哪个更擅长，就让哪个动手。
  • 每次执行和检查都可能产生服务商费用。成员越多，花费越多，但不一定更快。
  • 这个预览版里，群里的工作项是一个接一个做的。
  • 检查只覆盖它检查过的内容。收下之前，自己打开文件看一眼。
