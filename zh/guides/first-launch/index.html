Mac 或 Windows 打开 Botogether 时提示有风险，怎么办？

Botogether 预览版还没做 Apple 公证，也没有 Windows 签名，首次打开时系统可能提示风险。只从官方 GitHub Releases 下载，核对 SHA256 校验值，系统提供放行选项时，再按安装说明操作。

步骤

  1. 从官方页面下载

    在 GitHub Releases 下载 DMG（Mac）或 EXE（Windows）。Source code 压缩包只有文档，不是安装包。

  2. 核对校验值

    Mac 运行 shasum -a 256 加文件名；Windows 运行 Get-FileHash -Algorithm SHA256 加文件名。与发行页上对应平台的校验文件核对。

  3. Mac：允许一次

    打开 DMG，把 Botogether 拖进「应用程序」并尝试打开。如果被拦住，到「系统设置 → 隐私与安全性」，点 Botogether 旁边的「仍要打开」。

  4. Windows：允许一次

    运行 EXE。出现「Windows 已保护你的电脑」时，确认来源后点「更多信息」→「仍要运行」。

要注意

  • 不要关掉 Gatekeeper、SmartScreen 和杀毒软件，只对这一个应用放行。
  • 如果提示「已损坏」或有恶意软件，那是另一回事。先检查下载和校验值，不要直接跳过。
  • 如果被智能应用控制或公司策略拦住，保持防护开启，到 GitHub Issues 反馈。
  • 将下载文件的 SHA256 与发行页公布的值比较，核对文件字节是否一致。
