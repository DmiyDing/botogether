没装任何 AI 智能体，能用 Botogether 吗？

能。点「免费开始」，Botogether 会下载并检查 OpenCode，然后让你选一个当前可用的免费体验模型。不需要 Node.js、npm 或终端，也不会自己切到付费模型。

步骤

  1. 打开 Botogether

    从 GitHub Releases 下载安装。系统提示有风险的话，看「首次打开有安全提示」那篇。

  2. 点「免费开始」

    应用会帮你下载 OpenCode 并检查好。

  3. 选一个免费体验模型

    选一个现在可用的。名额和限制由服务方决定。

  4. 先试个小任务

    选一个项目目录，说一句「帮我列一个周末清单」。打开文件看看，再让它改。

要注意

  • 应用会在使用前重新检查可用性，也不会自动改用付费模型。
  • 以后可以再加 Claude Code、Codex 等智能体，拉进同一个群。
