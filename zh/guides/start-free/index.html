没装任何 AI 智能体，能用 Botogether 吗？

更新于 2026-11-23

能用。在 Botogether 欢迎页点击「免费开始」，应用会自动下载并检查 OpenCode，再把上游当前可用的免费体验模型列给你选。全程不需要配置 Node.js、npm 或打开终端，也不会在免费名额用完后悄悄切到付费模型。

操作步骤

  1. 下载并打开 Botogether

    从官方 GitHub Releases 下载 Mac（Apple Silicon）或 Windows x64 安装包。首次打开若遇系统提示，先看「首次打开有安全提示」教程完成校验并放行。

  2. 点击欢迎页的「免费开始」

    无需手动跑命令，应用会在内部完成 OpenCode 的下载与安装校验，省去装 Node.js 和配置环境变量的门槛。

  3. 挑一个当前可用的免费体验模型

    应用会先探测上游当前可用的免费模型列表供你选择。免费额度、速率限制和可用时段由模型服务方提供并决定。

  4. 选一个文件夹试一个小任务

    随便选一个你熟悉的本地目录，发一句小需求（例如「帮我整理这个目录的文件说明」或「列一份周末清单」），点开生成的文件看效果。

「免费开始（OpenCode）」与「接入本地已有 CLI」对比

如果你只是想先体验 Botogether 的工作台、本地文件交付与记忆管理，用「免费开始」几分钟就能跑通第一条真实任务；等你之后装上 Claude Code、Codex 或 Cursor，直接就能拉进同一个工作区继续用。

对比维度免费开始（OpenCode）接入已有工具（Claude Code / Codex / Cursor）
环境准备零命令行门槛，应用内直接装好 OpenCode需各自安装并登录（支持部分工具在设置里一键安装）
费用与额度选用上游提供的免费体验模型，不会静默转付费使用你自己的订阅账号或 API Key 计费
自定义服务扩展OpenCode 实验性支持接入 OpenAI Chat Completions 服务Claude Code 与 Codex 拥有各自专用适配与分组管理
多智能体协作可单聊使用，也能直接加入群聊与其他助手配合适合复杂编码与跨模型独立互查

免费模型限流或不可用时怎么处理？

每次执行前应用都会重新核对所选免费选项的可用性，绝不静默降级或自动切换到收费接口。如果某个免费体验模型临时达到上限或不可用，界面会明确提示，你可以切到列表里另一个可用的免费模型，或在「设置 → 模型与代理」里填入自己的 API Key。

注意事项

  • Botogether 应用本身完全免费且无需注册账号；具体免费体验模型的稳定性、速率和可用地区取决于对应服务方。
  • 若在 OpenCode 中配置自定义 OpenAI Chat Completions 服务，需明确填写模型名称列表，配置仅注入当前任务进程。
  • 不要把任何 API Key 写进助手名称、人设提示词、文件名或公开 Issue 里。

本篇常见问题

我电脑上没装 Node.js、Homebrew 或 npm，也能用吗？

可以。「免费开始」会在应用内部自动下载并校验 OpenCode，不需要你自己折腾终端或前端环境。

免费名额用完后会突然扣费吗？

不会。Botogether 没有账号和支付体系，也不会擅自帮你切换成付费接口；需要换模型时会明确交由你选择。

以后买了 Claude Code 或 Codex，以前的聊天和记忆还能留着吗？

全部保留在本地。打开「设置 → 智能体」检测或安装新工具后，就能在原有项目目录或群聊里继续配合使用。
