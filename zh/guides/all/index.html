Botogether 教程

短小、能照着做。每篇只回答一个问题。

首次打开有安全提示Botogether 预览版还没做 Apple 公证和 Windows 签名，首次打开会被系统提示。教你核对下载文件，在 Mac 和 Windows 上安全打开。阅读教程 →让 Claude Code 和 Codex 互相检查把 Claude Code 和 Codex 拉进同一个 Botogether 群：一个写，一个查，在同一个项目目录里交付真实文件。一步步教你配置。阅读教程 →没装智能体，免费开始没装过 Claude Code 或 Codex 也能用。Botogether 可以在应用里装好 OpenCode，选一个免费体验模型就能开始。不需要 Node.js、npm 或终端。阅读教程 →
