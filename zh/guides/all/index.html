从下载到协作的 3 步上手路线

  1. 1. 下载并核对安装包

    从官方 GitHub Releases 下载 Apple 芯片 Mac 版（DMG）或 Windows x64 版（EXE），先核对 SHA256 校验值，再按系统正常放行入口允许打开这一次。

  2. 2. 免费体验或接入已有工具

    还没装任何 AI 工具？点「免费开始」在应用内安装 OpenCode 并选可用免费体验模型。已有 Claude Code、Codex 或 Cursor？打开「设置 → 智能体」重新检测。

  3. 3. 绑定目录并核对交付结果

    单聊试试小任务，或建群放进两位助手并绑定同一个项目目录。在任务详情核对分工，点开文件差异与预览后再决定是否收下。
