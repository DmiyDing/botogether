常见问题

Botogether 是什么？

一款免费的 Mac 和 Windows 桌面应用。它把 Claude Code、Codex、Cursor 等多个 AI 智能体拉进同一个群聊，让它们分工合作、互相检查。

免费吗？

免费，没有订阅，也不用注册。智能体或模型服务可能另外收费。

支持哪些智能体？

原生与实验性接入：Codex、Claude Code、Cursor Agent、Gemini CLI、Qwen Code、OpenCode、CodeBuddy CLI、Kiro CLI、Cline、Kilo Code、Hermes Agent、Oh My Pi，其中部分还在打磨。能识别并附接入指引：GitHub Copilot CLI、Grok Build、DeepSeek Harness、Goose、Aider、Pi。

数据存在哪？

会话和任务文件留在你的电脑上。用云端模型时，你发出的内容会发给对应的服务方。

一个智能体都没装，能用吗？

能。点「免费开始」，会帮你装好 OpenCode，选一个免费体验模型就能用。

为什么电脑会提示有风险？

预览版还没做 Apple 公证，也没有 Windows 签名。请只从官方 GitHub Releases 下载，并核对 SHA256 校验值。

怎么安装？

Mac：打开 DMG，把 Botogether 拖进「应用程序」。Windows：运行 EXE；出现 SmartScreen 提示时，确认来源后点「更多信息」→「仍要运行」。

开源吗？

不开源。应用免费使用，采用专有许可。公开仓库里有使用说明和下载。
