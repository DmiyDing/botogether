入门指南

第一个有用的结果

选择与你的电脑匹配的安装包，先阅读未签名预览版的安装帮助。仓库的 Source code 压缩包只是文档，不是安装包。

  • 没装过 AI 工具：点「免费开始」→ 等待应用下载并检查 OpenCode → 选择可用的免费体验模型 → 开始聊天。不需要 Node.js、npm 或终端。免费名额会重新检查，不会自动改用付费模型。
  • 已有 AI 工具：从 + 创建助手，选择检测到的工具。在「设置 → 智能体」中，OpenCode、Codex 与 Claude Code 在受支持系统上可一键安装；其他工具提供明确安装说明。安装完成不等于已登录或已验证全部能力。
  • 选好会话文件夹，先试一个小任务并点开结果检查，再补充要求继续修改。需要访问权限时按正常授权入口处理。

群聊分工

从 + 创建群聊，至少选两位助手，并绑定群聊共享目录。明确分工，例如「@评审助手 负责检查，@编码助手 负责修改」，使用实际助手名称，并在任务详情核对分配。更多成员会增加协调与模型用量，不保证更快；当前工作项串行执行。

文件与过程

任务详情保留可见的活动与文件证据。图片默认适应弹窗，可切换原始尺寸或下载原文件。文件检查只验证已声明的检查项；回复和独立评审不代表全部需求已证明。接受文件前先核对。任务阻塞或执行效果未知时，不要假设重试安全。

记忆

「设置 → 记忆」可添加事实与偏好，并选择使用范围。内置记忆无需安装；MCP Memory 可启用；Basic Memory 可受管安装；Mem0 需先配置本机嵌入服务、模型与维度，其他方案在适配器完成前仅提供指南。更换模型或记忆引擎不会删除 Botogether 的本地权威记录，目前不提供记忆自动提取。

模型、权限与费用

在输入框或编辑助手时选择模型。原生模型可用性与登录由智能体账号决定；批准前核对权限范围。设置变更用于后续任务，不静默改写正在运行任务的配置快照。执行、评审与重试都可能产生服务商费用，缺少用量报告表示未知，不是零费用。

「设置 → 模型与代理」按 Agent 分组保存服务。Claude Code 与 Codex 已有专用适配；OpenCode 实验性支持 OpenAI Chat Completions 服务，配置仅注入当前任务进程。其他 Agent 继续使用自己的账号与原生配置。模型服务不等于系统网络代理。

安装帮助

测试预览版
macOS 未做公证，Windows 无发布者签名。请保留 Gatekeeper、SmartScreen 与杀毒软件；遇到「已损坏」或恶意软件警告，应重新核对下载与完整性，不要盲目忽略。

macOS

打开 DMG，将 Botogether 拖入「应用程序」后尝试打开。如 macOS 拦截此预览版，在系统提供选项时前往「系统设置 → 隐私与安全性」，对这个应用选择「仍要打开」。

Windows

运行 EXE。如出现「Windows 已保护你的电脑」，核对来源后在系统提供选项时选择「更多信息 → 仍要运行」。若 Smart App Control 或单位策略阻止安装，请保留保护并反馈提示。

核对完整性

shasum -a 256 Botogether-0.1.0-preview.11-mac-arm64.dmg      # macOS
Get-FileHash -Algorithm SHA256 Botogether-0.1.0-preview.10-win-x64.exe   # Windows

与官方 Releases 中的 SHA256SUMS 逐项比对。校验和只证明字节一致，不代表发布者身份认证。

问题排查

发布页没有安装包？
只有已发布版本中列出的安装文件才可下载。此仓库存放下载说明，不是应用源码；克隆它不能代替安装。npm 安装尚未提供。
没有可用智能体？
打开「设置 → 智能体」重新检测，使用对应安装与登录引导。安装包不内置 Agent，请按官方指南自行安装并登录。登录或能力检查失败时先查看原因，不要反复创建助手；不要把密钥写在助手名称、提示词或记忆中。
旧界面或错误下载链接？
源码修改不会自动更新已安装的应用。退出旧应用，安装经过核对的新版，再从正常安装入口启动。官方下载仓库为 DmiyDing/botogether，下载不需要私有仓库权限。「设置 → 关于与更新」在可用时显示版本与构建身份。
无法检查更新？
测试版检查已发布的测试版与稳定版，稳定版只检查稳定更新。没有已发布版本、网络失败或 GitHub 限制都可能导致无法检查，「无法检查」不等于「最新」。先确认工作已停止再退出，更新不会自动中断任务，安装前请备份数据。
图片预览失败？
使用原文件下载入口查看。不支持或不安全的 SVG 保留为下载附件，预览失败不会删除文件。预览可能经过安全处理，原文件下载保留原始字节。
想删除聊天？
删除后聊天从侧栏与搜索消失，不提供已删除聊天浏览入口。内部墓碑用于任务一致性，并不代表擦除磁盘上的全部历史。运行中的任务、群成员引用或启用的定时任务可能阻止删除。

隐私说明

Botogether 在本地保存聊天、配置、有范围的记忆与文件快照。macOS 桌面数据位于 ~/Library/Application Support/Botogether，Windows 使用当前用户的 Botogether 应用数据位置。分享这些目录或记忆导出前应先检查内容。

本地保存不等于模型离线运行。所选智能体或服务商可能将获准的提示词、项目数据与范围内记忆发送到其模型服务，请了解对应隐私条款。官方更新检查访问公开分发仓库，不附带模型凭据、聊天或记忆正文。

原生 Agent 登录由对应 Agent 管理。自定义服务的系统加密方式将 API Key 密文保存在本机，macOS 钥匙串保护加密密钥，可能要求授权。Botogether 不自动将已有密钥迁移到其他存储方式或写入 Agent 原生配置。
