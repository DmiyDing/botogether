为什么选择 Botogether

把「模型说完成了」变成「你能查到的结果」

Botogether 不替智能体背书。它把权限、过程和文件摆在你面前，让交付可以被检查。

同一个聊天，不同的分工

让一位助手处理，或由小队先制作、再检查。群聊里用 @ 点名成员，任务详情里核对分配结果。

记录保存在本机

会话、配置、作用域记忆和文件快照都留在你的电脑上。所选 Agent 与模型服务仍可能按其条款把提示词或文件发往云端。

权限可见，成果可查

选择项目目录，逐项处理授权，展开执行时间线查看每一步。智能体说「完成」不等于交付已通过检查。

可以做什么

一个桌面工作区，覆盖从对话到交付

以下能力在当前预览版中可用；具体表现取决于你选择的智能体、模型与工具。

私聊与群聊

单个助手专注一件事，或组建小队共同完成一项任务，用 @ 点名成员。

共用项目文件夹

为会话绑定工作目录，保存每个助手的分工，检查之后定向返工。

每个助手可选模型

在输入框或助手设置中指定模型与作用域指令，不同成员可使用不同配置。

可见的授权与执行记录

待处理授权保持可见，处理过的记录默认折叠，时间线可展开到单条事件。

文件与图片预览

直接预览任务产出的文件与图片，并下载原始文件核对字节。

本地作用域记忆

保存事实与偏好并限定使用范围；更换模型或记忆引擎不会删除本地记录。

当前预览版不提供
手机远程控制、通用插件安装与完整的 MCP 工具管理。各引擎与模型能力不同，实际验证范围以版本说明为准。

常见问题

下载前你可能想确认的几件事

免费吗？
应用本身没有订阅费。Agent 账号、模型和第三方服务各有自己的条款与价格，执行、检查和重试都可能产生服务商费用；缺少用量报告表示未知，不是零费用。
我的数据在哪里？
Botogether 把聊天、配置、作用域记忆和文件快照保存在本机（macOS 位于 ~/Library/Application Support/Botogether）。但本地保存不等于离线推理：使用云模型时，任务内容可能发送给对应服务方。
支持哪些 Agent？
应用会检测受支持的本地安装并提供安装或配置引导；在受支持系统上，OpenCode、Codex 和 Claude Code 可在应用内一键安装。其他引擎功能取决于其自身版本与能力。
开源吗？
不是。Botogether 采用专有发行许可，公开仓库提供说明文档与下载入口，不包含应用源码。
会安装 npm 包吗？
不会提供 npm 安装。桌面安装包是独立分发物，Source code 压缩包只是本公开仓库的文档。
怎么反馈问题？
在 Issues 中提供版本、操作系统与复现步骤。Issue 公开可见，请遮盖截图中的隐私信息，不要上传凭据、数据库、聊天导出或私人项目文件。
