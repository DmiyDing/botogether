No AI agent installed? Start Botogether for free with OpenCode

Updated 2026-11-23

Yes. Click “Start for free” on Botogether’s welcome screen: the app downloads and verifies OpenCode inside the app and shows currently available free trial models. You do not need Node.js, npm, or terminal setup, and Botogether never silently switches you to a paid model.

Steps

  1. Install and open Botogether

    Download the DMG (Apple Silicon Mac) or EXE (Windows x64) from official GitHub Releases. If your OS shows a first-launch warning, follow the First-Launch Security guide to verify SHA256 and allow the app once.

  2. Click “Start for free”

    On the welcome screen, choose “Start for free”. Botogether downloads OpenCode, verifies the installation inside the app, and checks which free trial models are currently offered by the upstream catalog.

  3. Pick an available free model

    Select one of the free options listed as available now. Free model availability, context limits, and rate limits come from the upstream provider rather than Botogether.

  4. Run a small real-folder task

    Pick a local project folder (or create a small test folder) and try a concrete prompt like creating a project checklist or summarizing markdown notes. Open the delivered file in chat to inspect or download it.

Start for free (OpenCode) vs. bringing your own CLI tools

“Start for free” is the fastest way to evaluate Botogether’s workspace, file previews, permissions, and scoped memory without configuring paid CLI subscriptions up front. When you later install Claude Code, Codex, or Cursor, you can mix them right alongside your OpenCode assistant.

What happens if a free model hits a rate limit or becomes unavailable?

Botogether rechecks free model availability before running a task and never silently substitutes a paid endpoint. If an upstream free model reaches its rate limit or temporarily goes offline, Botogether shows the error or availability status clearly so you can switch to another available free option, configure your own API key in Settings → Models & services, or connect an existing CLI.

Good to know

  • Botogether itself is free to use with no account or subscription, though third-party model providers set their own free tier limits and terms.
  • If you configure a custom OpenAI Chat Completions provider for OpenCode, provide an explicit model list; the configuration is injected only into that task process.
  • Never paste API keys into assistant names, chat prompts, filenames, or public issue reports.

Questions about this guide

Do I need to install Node.js, Homebrew, or npm first?

No. When you click “Start for free”, Botogether handles downloading and checking OpenCode inside the app without requiring terminal commands.

Will Botogether ever charge my card or switch to a paid model automatically?

No. Botogether does not have user accounts, billing, or subscriptions, and it will not silently fall back from a free trial model to a paid model.

Can I add Claude Code or Codex later without losing my chats?

Yes. Your chats, folders, and local Botogether memories stay on your machine. You can detect or install additional agents anytime in Settings → Agents and add them to existing or new groups.
