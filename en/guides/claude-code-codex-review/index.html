How to make Claude Code and Codex check each other’s work

Create a group in Botogether with a Claude Code assistant and a Codex assistant, bind one shared project folder, and say who does what: for example “@Builder make the change, @Reviewer check it.” Check the task details to confirm the assignments before relying on the review.

Steps

  1. Install both agents

    Botogether finds Claude Code and Codex if they are already on your computer. In Settings → Agents it can also install them on supported systems. You still sign in with your own account.

  2. Create two assistants

    Click + and create one assistant on Claude Code and one on Codex. Give each a clear name, like Builder and Reviewer, and its own model.

  3. Make a group with one folder

    Click + again, create a group with both assistants and bind the project folder they should work in.

  4. Say who builds and who checks

    Use their real names: “@Builder fix the checkout layout on small phones. @Reviewer check it on three screen sizes.”

  5. Read the result

    Check who was assigned in the task details and inspect the file evidence. If a check or change is still needed, address the appropriate assistant by name.

Good to know

  • Either agent can be the builder. Swap them if one is better at the job.
  • Every run and review can cost usage with your agent provider. More members add cost; they do not always make it faster.
  • Work items in a group run one after another in this preview.
  • A review only covers what was checked. Open the files before you accept them.
