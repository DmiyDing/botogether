Mac or Windows warns when you open Botogether? Here is why and what to do

The Botogether preview is not notarized by Apple and has no Windows publisher signature yet, so macOS or Windows may show a warning the first time you open it. Download it only from the official GitHub Releases, check the SHA256 checksum, then follow the installation help if your system offers an option to allow the app.

Steps

  1. Download from the official page

    Get the DMG (Mac) or EXE (Windows) from GitHub Releases. Source code archives are documentation only, not installers.

  2. Check the checksum

    Mac: run shasum -a 256 with the file name. Windows: run Get-FileHash -Algorithm SHA256 with the file name. Compare it with the checksum file for your platform on the release page.

  3. Mac: allow it once

    Open the DMG and drag Botogether into Applications and try opening it. If macOS blocks it, go to System Settings → Privacy & Security and click Open Anyway for Botogether.

  4. Windows: allow it once

    Run the EXE. If “Windows protected your PC” appears, check the source, then choose More info → Run anyway.

Good to know

  • Keep Gatekeeper, SmartScreen and your antivirus on. You only allow this one app.
  • A “damaged” or malware warning is different. Check the download and the checksum instead of skipping it.
  • If Smart App Control or your company policy blocks the install, keep the protection on and report it in GitHub Issues.
  • Compare the SHA256 of your download with the value published on the release page. This checks byte consistency.
