Mac or Windows warns when you open Botogether? Here is why and what to do

Updated 2026-11-23

The Botogether preview is not notarized by Apple and has no Windows publisher signature yet, so macOS Gatekeeper or Windows SmartScreen may show a warning on first launch. Download only from the official DmiyDing/botogether Releases page, verify the SHA256 checksum against the published checksum file, and use the per-app allow option only if your system offers one.

Steps

  1. Download from the official Releases page

    Get the Apple Silicon Mac DMG (or ZIP) or Windows x64 EXE (or ZIP) from official GitHub Releases. Source code archives contain documentation only and are not application installers.

  2. Verify the SHA256 checksum before opening

    Replace the example filename in the command below with your downloaded installer path, then compare its SHA256 hash with the matching *-SHA256SUMS.txt file on the release page. Remember that a matching checksum proves byte consistency with the release asset—it does not replace publisher notarization.

  3. macOS: allow this single app once

    Open the DMG, drag Botogether into Applications, and try launching it. If macOS blocks it as an unidentified developer, open System Settings → Privacy & Security, scroll to the notice for Botogether, and click Open Anyway.

  4. Windows: allow via More info → Run anyway

    Run the EXE installer. If “Windows protected your PC” appears, verify that the file came from the official GitHub Releases page and matches SHA256, then click More info → Run anyway.

How to read each system warning

Different system prompts require different responses. Never turn off Gatekeeper, SmartScreen, or your antivirus globally just to install a preview app.

Security boundaries during updates

Official update checks inside Botogether query only the public DmiyDing/botogether repository and never send model credentials, chat history, or memory content. When upgrading manually, make sure active tasks have stopped cleanly before quitting the older copy, and back up your data directory if you are testing major preview changes.

Good to know

  • Keep Gatekeeper, SmartScreen, Smart App Control, and antivirus enabled at all times; do not disable system protections or strip quarantine globally.
  • Intel Mac new builds are currently paused. Only Apple Silicon Mac and Windows x64 receive current preview installers.
  • Keep one standard installed copy in Applications (Mac) or your normal install location (Windows) rather than running extra copies from build folders.

Questions about this guide

Why does Botogether show a security warning right now?

Current public previews are not notarized with an Apple Developer ID or signed with a Windows Authenticode certificate yet. Check the release notes for the signing status of the version you download.

Does a matching SHA256 mean the file is completely safe?

A matching SHA256 proves the bytes you downloaded match the checksum published on the GitHub Release page. You should still confirm you downloaded from DmiyDing/botogether and review the privacy and permission prompts inside the app.

What if macOS Privacy & Security does not show “Open Anyway”?

Try launching Botogether once from Finder → Applications first so macOS logs the blocked attempt, then reopen System Settings → Privacy & Security. If your Mac is managed by a company policy that forbids unsigned apps, keep the policy intact.
