What is Botogether?

Botogether is a free desktop app for Mac and Windows that turns the AI agents on your computer into a team. They chat in one group, split the work, check each other, and deliver real files to the folder you choose.

Questions

What is Botogether?

A free desktop app for Mac and Windows that puts several AI agents, such as Claude Code, Codex and Cursor, into one group chat so they can split work and check each other.

Is it free?

Yes. There is no subscription and no account. Your agent or model provider may charge separately.

Which agents work?

Native and experimental integrations: Codex, Claude Code, Cursor Agent, Gemini CLI, Qwen Code, OpenCode, CodeBuddy CLI, Kiro CLI, Cline, Kilo Code, Hermes Agent and Oh My Pi. Experimental integrations depend on your CLI version and configuration. Detected with a setup guide: GitHub Copilot CLI, Grok Build, DeepSeek Harness, Goose, Aider and Pi.

Where is my data?

Chats and task files stay on your computer. If you use a cloud model, the content you send goes to that provider.

I have no agent installed. Can I try it?

Yes. Choose “Start for free” to install OpenCode and pick a free trial model.

Why does my computer warn me?

The preview is not notarized by Apple and has no Windows publisher signature. Download only from the official GitHub Releases and compare the SHA256 checksum.

How do I install it?

Mac: open the DMG and drag Botogether into Applications. Windows: run the EXE; if SmartScreen appears, check the source, then choose “More info” → “Run anyway”.

Is it open source?

No. Botogether is free to use under a proprietary license. The public repository has the guides and downloads.
